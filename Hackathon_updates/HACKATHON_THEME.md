# AI for Civic Innovation Hackathon 2026

## Theme 3 — Open Data & Access to Information

Solutions that make public information more accessible, understandable, transparent, and useful for citizens.

### Example solution areas

- Open data dashboards
- Budget transparency tools
- Information accessibility systems
- Fact-checking tools

---

## How Court Companion maps to Theme 3

| Theme expectation | Court Companion alignment |
|-------------------|---------------------------|
| Make public information **accessible** | Bilingual (EN/Urdu) chat + voice support for low-literacy users |
| Make information **understandable** | RAG-grounded answers that simplify PPC/CrPC legal language |
| Improve **transparency** | Responses cite retrieved legal sources, not opaque LLM guesses |
| Make information **useful** | Focused criminal-law Q&A (FIR, arrest rights, bail, PPC sections) |

**Niche focus:** Pakistan criminal law awareness for citizens — not the entire legal ecosystem.
